# Telegram-бот «Слово дня»

Раз в день бот постит в канал случайное слово из `data.js` в виде вопроса
с 4 кнопками-вариантами ответа (3 дистрактора берутся из той же темы).
Кликнувший получает всплывающую подсказку верно/неверно, ответ пишется в лог.

## Почему не нативный Telegram Quiz

Изначально предполагался нативный `sendPoll(type=quiz)`. Оказалось, что
Telegram не разрешает не-анонимные опросы в каналах, а у анонимных опросов
бот не получает user_id ответившего — только агрегированные цифры по вариантам.
Логировать "кто именно ответил" через нативный quiz в канале невозможно в принципе.

Поэтому вместо Poll — обычное сообщение с inline-кнопками. Клик по кнопке
всегда приходит боту вместе с `user_id`, независимо ни от чего, поэтому
работает и полноценный лог по людям, и еженедельный топ.

Плата за это: два процесса вместо одного.

- **`post_quiz.py`** — разовый скрипт, публикует пост. Запускается раз в
  сутки по расписанию (Планировщик задач / cron).
- **`bot_listener.py`** — должен работать **постоянно**, слушает клики по
  кнопкам. Без него кнопки будут просто крутиться у пользователей, пока
  бот снова не запустится (Telegram придержит клики как pending-обновления,
  но ответит на них бот только когда снова окажется онлайн).

## 1. Создать бота

1. Написать [@BotFather](https://t.me/BotFather) → `/newbot` → следовать инструкциям.
2. Скопировать выданный токен (вида `123456:AA...`) — это `BOT_TOKEN`.

## 2. Добавить бота в канал

1. Открыть канал → **Administrators** → **Add Admin** → выбрать своего бота.
2. Прав достаточно минимальных: **Post Messages** и **Edit Messages of Others**
   (второе нужно, чтобы бот мог обновлять счётчик "сколько ответили" под своим же постом).

## 3. Узнать CHANNEL_ID

- Если канал публичный — просто username с `@`, например `@deutsch_tools`.
- Если приватный — перешлите любое сообщение из канала боту [@userinfobot](https://t.me/userinfobot)
  или [@JsonDumpBot](https://t.me/JsonDumpBot), в JSON будет числовой `chat.id`
  (обычно вида `-1001234567890`, с минусом).

## 4. Установка

```bash
cd telegram-bot
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## 5. Конфиг

```bash
copy .env.example .env
```

Открыть `.env` и заполнить:

```
BOT_TOKEN=<токен от BotFather>
CHANNEL_ID=<@username или -100...>
SITE_URL=https://r4-studio.github.io/deutsch-tools
LINK_PROBABILITY=0.5
```

`LINK_PROBABILITY` — шанс (0..1), что во всплывающей подсказке после ответа
будет ссылка на сайт с неформальным призывом. `0.5` = через раз.

`.env`, `state/` и `logs/` уже в `.gitignore` — в `logs/answers.jsonl` лежат
Telegram user_id и username, это не должно уезжать в публичный репозиторий.

## 6. Проверить руками

```bash
python post_quiz.py
```

Должен появиться пост в канале. Затем в отдельном терминале:

```bash
python bot_listener.py
```

и нажать кнопку под постом — должна появиться всплывашка и обновиться счётчик.

## 7. Расписание для post_quiz.py (раз в сутки, 6:00)

**Windows (Планировщик заданий):**

```
schtasks /create /tn "DeutschTools WordOfDay" /tr "\"D:\r4-GitHub\deutsch-tools\telegram-bot\venv\Scripts\python.exe\" \"D:\r4-GitHub\deutsch-tools\telegram-bot\post_quiz.py\"" /sc daily /st 06:00
```

Или через GUI: **Планировщик заданий → Создать задачу** → Триггер: ежедневно 06:00 →
Действие: запустить программу `venv\Scripts\python.exe` с аргументом
`post_quiz.py` и рабочей папкой `telegram-bot`.

**Linux/macOS (cron):**

```
0 6 * * * cd /path/to/deutsch-tools/telegram-bot && venv/bin/python post_quiz.py
```

## 8. bot_listener.py — постоянный процесс

Это не cron-задача, а долгоживущий процесс (слушает Telegram через long polling).

**Windows** — проще всего через Планировщик заданий: триггер "При запуске
системы", действие — тот же `python.exe` с аргументом `bot_listener.py`,
галка "Выполнять независимо от того, вошёл ли пользователь в систему".
Либо вручную держать открытым окно терминала / использовать `pythonw.exe`
вместо `python.exe`, чтобы не маячило окно консоли.

**Linux** — `systemd`-юнит или `screen`/`tmux`-сессия:

```
screen -S dt-bot
cd /path/to/deutsch-tools/telegram-bot && venv/bin/python bot_listener.py
# Ctrl+A, D — отсоединиться от сессии, процесс продолжит работать
```

## 9. Еженедельный топ

```bash
python weekly_stats.py        # за последние 7 дней
python weekly_stats.py 14     # за произвольное число дней
```

Печатает таблицу «пользователь — верно — всего — %», отсортированную по
числу верных ответов. Дальше — вручную оформляется картинкой, как и
планировалось в брифе.

## Структура

```
telegram-bot/
  post_quiz.py       — разовый постинг (по расписанию)
  bot_listener.py     — постоянный слушатель кнопок (лог + попапы + счётчик)
  quiz_data.py        — парсит VOCAB из ../data.js, строит вопрос+дистракторы
  explanations.py     — доп. текст к попапу (пример/заметка + иногда ссылка)
  weekly_stats.py      — агрегация logs/answers.jsonl в топ
  config.py            — .env → константы
  state/               — posted_polls.json, recent_words.json (не в git)
  logs/                 — answers.jsonl (не в git, там user_id/username)
```
