Deutsch Tools - это набор инструментов для помощи в изучении языка. Оно не заменяет полное обучение, но дает инструменты для усвоения новых правил и отработки материалов.
 
Из чего состоит инструмент: Инструмент состоит из: Справочника и Тренажёра.
 
1. Справочник - это база данных: слова и правила для изучения - по сути оправдывает название.
2. Тренажёр - это инструмент в помощи изучения у которого есть два режима: тестирование и изучение.
 
Режимы изучения: Изучение - это карточки изучения слов с мини тестами для проверки запоминания того как ты усвоил. Тестирование - это расширенные тесты по материалу. Они состоят из 5 разных уровней (на данный момент доступно 4/5). 
 
Ур.1 — перевод (все части речи)
Ур.2 — склонение формы слова: феминитив / множественное число / артикль (род) / компаратив прилагательных / склонение прилагательных (алгоритмически из падежа) / личные и притяжательные местоимения
Ур.3 — склонение в предложении: артикль+прилагательное в контексте по падежам (Nom/Akk/Dat/Genitiv), таблица спряжения глагола — включая Perfekt/Präteritum как отдельные варианты внутри (решить: тест на все времена сразу или отдельные кнопки-режимы, как сейчас)
Ур.4 — составление предложений плитками
Ур.5 — свободный ввод перевода предложения (новый уровень, сейчас не существовал вообще)

**Флаг «новое» (`new`) в базе данных:** колонка `new` есть на всех контентных листах xlsx. Три состояния: пусто/`FALSE` — обычная запись, ничего не показывается; `TRUE`/`1`/`x`/`yes`/`да` — новая запись, попадает в буфер «Neu» на сайте; `Update`/`upd`/`u`/`обновлено` — существующую запись отредактировали, тоже попадает в буфер «Neu», но в консольном отчёте `update_data.py` помечается отдельно как `↻ aktualisiert`. Регистр не важен. Флаг не сбрасывается сам — снимать вручную в xlsx, когда запись больше не нужно показывать как «новую».
